# KOS: Future Lightweight Linux Distribution

## The Vision

In the near future, we plan to prepare our own Linux distribution: **KOS**.

A super-light, useful system for both **developers** and **normal users**, built from proven, minimal components.

## Core Stack

| Component | Purpose |
|-----------|---------|
| **X Server** | Display server |
| **OpenBox** | Window manager (KosBox) |
| **KosDWM5** | Dynamic panel for managing windows |
| **KosFM** | File manager |
| **+ more tools** | Coming as the ecosystem grows |

## UI Toolkit Choice

Users will be able to choose between:

- **Python Tkinter** — lighter, simpler, works on weaker hardware
- **Python PyQt5** — stronger, richer UI, for more powerful machines

This lets KOS scale from old laptops to modern workstations.

## Target Audience

- 👨‍💻 **Developers** — minimal, fast, configurable environment
- 🏠 **Normal users** — lightweight desktop that just works
- 🖥️ **Low-end hardware** — choose Tkinter for less resource usage
- ⚡ **Power users** — choose PyQt5 for richer experience

## Why This Matters

- 🪶 **Lightweight** — no bloat, just what you need
- 🔧 **Modular** — built from our own KosGen tools
- 🐍 **Python-first** — familiar tooling for customization
- 🎯 **Consistent ecosystem** — KOS ties together KosBox, KosDWM5, KosFM, and future tools

## Name

> **KOS** — our new operating system.
